# 40. 파일 올리고 데이터 정리하기

엑셀 파일이 지저분해서 손대기 싫었던 경험이 누구나 있다. 날짜 형식이 제각각이고, 빈칸이 있고, 같은 이름이 다르게 적혀 있다. ChatGPT에 파일을 올리면 이런 정리 작업을 말로 시킬 수 있다. 엑셀을 잘 못 다뤄도 된다. "해줘"라고 말하면 된다.

![ChatGPT로 하는 데이터 업무 흐름](../assets/fig-data-flow.png)

### 파일 올리기

채팅창에 엑셀 파일이나 CSV 파일을 끌어다 놓으면 된다. 올린 뒤에는 파일 내용을 먼저 확인시킨다. "이 파일의 열 이름과 행 개수를 알려줘"라고 하면 된다. 그래야 AI가 파일을 제대로 읽었는지 알 수 있다. 열 이름이 한글이 깨지거나 하면 파일 형식을 확인하자.

### 정리 시키기

정리는 이렇게 시킨다. "날짜 열의 형식을 YYYY-MM-DD로 통일해줘", "빈칸인 행을 찾아서 알려줘", "'홍길동'과 '홍 길동'을 같은 사람으로 합쳐줘". 하나씩 순서대로 시키는 것이 요령이다. 한 번에 여러 개를 시키면 놓치는 것이 생긴다.

정리가 끝나면 결과를 새 파일로 받는다. "정리된 결과를 엑셀 파일로 만들어줘"라고 하면 다운로드할 수 있는 파일이 생긴다. 받은 파일은 꼭 열어보고, 행 개수와 합계 같은 기본 숫자가 원본과 맞는지 확인한다. AI의 정리는 빠르지만 완벽하지 않다.

### 분석 시키기

정리된 데이터를 분석한다. "월별 매출 합계를 표로 만들어줘", "가장 많이 팔린 상품 상위 5개를 알려줘", "전월 대비 증감률을 계산해줘"처럼 말한다. ChatGPT는 파일을 읽고 계산을 수행하는 기능이 있어서, 웬만한 집계는 바로 해준다.

분석 결과를 말로 설명해 달라고 할 수도 있다. "이 표를 보고 보고서에 쓸 한 단락 해석을 써줘"라고 하면 숫자를 문장으로 풀어준다. 다만 숫자의 정확성은 내가 책임진다. 중요한 보고서는 원본 파일의 숫자와 대조하는 검산을 마지막 단계로 꼭 넣자.

### 실습

실제 업무 엑셀 파일 하나를 복사본으로 만들어 올린 뒤, 열 이름과 행 개수를 확인하고, 날짜 형식 통일 하나만 시켜 보자. 결과 파일을 받아 원본과 비교해 보자.
