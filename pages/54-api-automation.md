# 54. API와 외부 연결 맛보기

ChatGPT를 다른 프로그램과 연결하면, 채팅창을 벗어난 자동화가 된다. 예를 들어 고객 문의 메일이 오면 자동으로 분류해서 담당자에게 전달하거나, 매일 매출 숫자를 받아서 보고서 초안을 만드는 식이다. 이 장에서는 코드를 짜지 않고 개념만 이해한다. 실제로 만들 때는 개발자의 도움을 받거나 자동화 도구를 쓴다.

### API란 무엇인가

API는 프로그램끼리 대화하는 창구다. ChatGPT에도 API가 있어서, 개발자는 채팅창이 아니라 자기 프로그램에서 ChatGPT의 기능을 쓸 수 있다. 예를 들어 회사 홈페이지의 문의 폼에 들어온 글을 API로 ChatGPT에 넘기면, 분류와 초안 답변이 자동으로 만들어진다. 직원은 그 답을 확인하고 보내기만 하면 된다.

API를 쓰면 요금이 따로 든다. 쓴 만큼 내는 방식이라, 대량으로 자동화할 때는 비용 계산이 필요하다. 소규모로 시작해 효과를 확인하고 늘리는 것이 좋다.

### 코드 없이 연결하는 방법

코드를 못 짜도 연결할 수 있는 방법이 있다. 자동화 도구(Make, Zapier 같은)를 쓰면 "메일이 오면 ChatGPT에 넘기고, 결과를 스프레드시트에 적는다" 같은 흐름을 마우스 클릭으로 만들 수 있다. ChatGPT의 예약 작업이나 Work도 넓은 의미의 자동화다. 채팅창 안에서 해결되는 자동화부터 시작하는 것이 순서다.

연결할 때 가장 중요한 것은 권한이다. ChatGPT가 회사 메일이나 파일에 접근하게 하려면, 어디까지 접근할지를 정해야 한다. 꼭 필요한 것만 연결하고, 접근 기록을 주기적으로 확인한다. 연결을 끊을 때는 도구의 설정에서 직접 해제한다. 편리함과 보안은 맞바꾸는 관계가 아니라, 함께 설계하는 것이다.

### 무엇부터 연결할까

처음 연결해 볼 만한 것은 세 가지다. 첫째, 자주 오는 문의 메일의 분류와 초안 작성. 둘째, 정기 보고서의 숫자 집계와 초안. 셋째, 회의록의 자동 정리와 공유. 셋 다 이 책에서 다룬 내용의 연장선이다. 채팅창에서 잘 되던 일이, 연결하면 사람의 손을 거치지 않고 돌아간다.

다만 자동화는 "잘 되던 일"에만 적용한다. 채팅창에서도 제대로 안 되던 일을 자동화하면, 틀린 일이 자동으로 반복될 뿐이다. 먼저 손으로 세 번 이상 성공한 다음에 자동화를 검토하자. 이것이 자동화의 황금률이다.

### 실습

내 업무 중에서 "매번 같은 순서로 하는 일"을 하나 골라 순서도로 그려 보자. 각 단계마다 "사람이 해야 하는가, AI가 할 수 있는가"를 표시한다. AI가 할 수 있는 단계가 세 개 이상이면 자동화 후보다.
