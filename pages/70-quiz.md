# 70. 확인 문제와 해설

### 문제 1

다음 중 OpenAI의 프롬프트 가이드에서 말하는 좋은 프롬프트의 네 가지 요소가 아닌 것은?

1. 목표
2. 맥락
3. 출력 형식
4. 모델의 내부 동작 원리

해설: 정답은 4번이다. 네 가지 요소는 목표, 맥락, 출력 형식, 경계다. 모델의 내부 동작을 이해할 필요는 없다. 중요한 것은 원하는 결과의 모습을 설명하는 것이다.

### 문제 2

"더 좋게 해줘"라는 수정 요청이 효과적이지 않은 이유는?

1. ChatGPT가 칭찬을 이해하지 못해서
2. 고칠 방향이 불분명해서
3. 수정 횟수에 제한이 있어서
4. 한국어로는 수정을 못 해서

해설: 정답은 2번이다. "더 좋게"에는 방향이 없다. "두 번째 단락을 절반으로 줄여줘"처럼 고칠 곳을 짚어줘야 한다.

### 문제 3

숫자가 들어가는 보고서를 ChatGPT와 함께 쓸 때 가장 안전한 방법은?

1. 숫자를 ChatGPT가 계산하게 맡긴다
2. 숫자는 내가 직접 적어 주고 문장으로 풀어 달라고만 한다
3. 숫자는 보고서에서 뺀다
4. 숫자는 대략적으로 적는다

해설: 정답은 2번이다. ChatGPT는 숫자를 지어내는 경우가 있다. 숫자는 내가 책임지고, AI에게는 문장으로 풀어 달라고 하는 분업이 안전하다.

### 문제 4

커스텀 지침의 두 칸에 들어갈 내용으로 알맞은 것은?

1. 첫 번째 칸: 오늘의 날씨, 두 번째 칸: 점심 메뉴
2. 첫 번째 칸: 나에 대한 정보, 두 번째 칸: 원하는 답의 방식
3. 첫 번째 칸: 비밀번호, 두 번째 칸: 계좌번호
4. 첫 번째 칸: 회사 기밀, 두 번째 칸: 고객 개인정보

해설: 정답은 2번이다. 첫 번째 칸에는 직무 같은 나에 대한 정보를, 두 번째 칸에는 말투나 형식 같은 원하는 답의 방식을 쓴다. 3번과 4번 같은 민감한 정보는 절대 입력하지 않는다.

### 문제 5

기준일 현재 개인 계정(Free, Go, Plus, Pro)의 GPT에 대한 설명으로 옳은 것은?

1. 새 GPT를 자유롭게 만들고 공개할 수 있다
2. 새 GPT를 만들 수 없지만 이미 만든 GPT는 계속 쓸 수 있다
3. 기존 GPT도 모두 삭제되었다
4. 모바일에서만 GPT를 만들 수 있다

해설: 정답은 2번이다. 개인 계정에서는 새 GPT 생성과 공개가 중단되었고, 기존 GPT는 계속 쓸 수 있다. OpenAI는 플러그인으로의 이전을 안내하고 있다.

### 문제 6

자영업자 사장님이 ChatGPT에게 메뉴 설명을 부탁할 때 가장 먼저 해야 할 일은?

1. "메뉴 설명 써줘"라고 짧게 말한다
2. "우리 가게는 OOO이야"처럼 가게 상황을 알려준다
3. 유료 요금제에 가입한다
4. 컴퓨터를 켠다

해설: 정답은 2번이다. AI는 내 가게를 모른다. 가게 상황을 한 줄로 알려주면 어떤 가게에도 붙일 수 있는 말이 아니라 내 가게의 말이 나온다. 스마트폰만으로 충분하다.

### 문제 7

예약 작업에 맡기기 좋은 일의 조건으로 알맞지 않은 것은?

1. 정해진 시간에 하는 일
2. 정해진 형식으로 나오는 일
3. 내가 확인만 하면 되는 일
4. 판단이 필요하고 실수가 치명적인 일

해설: 정답은 4번이다. 판단이 필요하거나 실수가 치명적인 일은 자동화에 맡기지 않는다. 예약 작업의 결과는 반드시 내가 확인하고 쓴다.

### 문제 8

업무 자동화를 시작하기 전에 지켜야 할 황금률은?

1. 채팅창에서 세 번 이상 성공한 일부터 자동화한다
2. 일단 연결하고 나중에 고친다
3. 모든 권한을 한 번에 연다
4. 자동화는 개발자만 한다

해설: 정답은 1번이다. 채팅창에서도 제대로 안 되던 일을 자동화하면 틀린 일이 자동으로 반복될 뿐이다. 먼저 손으로 성공을 확인한 다음에 자동화를 검토한다.
