# ChatGPT 업무 활용 실전

보고서, 이메일, 엑셀부터 GPTs와 자동화까지 — 회사에서 바로 쓰는 ChatGPT 활용법. 회원가입부터 프롬프트 작성, 문서 작성, 데이터 정리, 나만의 업무 파트너 만들기, 자동화 맛보기까지 차례대로 따라가는 실전서다. 자영업자 사장님이 스마트폰 하나로 쓰는 실전 장면도 별도 챕터로 다룬다.

## 구성

- Part 1. 시작하기 — ChatGPT의 원리, 계정과 요금제, 채팅·음성·파일 세 가지 화면
- Part 2. 프롬프트 작성 기본기 — 네 가지 요소(목표·맥락·출력 형식·경계), 역할과 맥락, 형식과 예시, 답 고치기
- Part 3. 문서 작성 실무 — 이메일, 보고서와 기획서, 회의록과 요약
- Part 4. 데이터와 엑셀 — 파일 올리고 정리하기, 엑셀 수식과 그래프
- Part 5. 나만의 업무 파트너 만들기 — 커스텀 지침과 메모리, GPTs, 이미지와 음성 기능
- Part 6. 자동화 맛보기 — 예약 작업과 ChatGPT Work, API와 외부 연결
- 관심 주제 — 자영업자 사장님의 하루
- 실전 프로젝트 — 나만의 업무 매뉴얼 만들기
- 확인 문제와 해설, 마무리
